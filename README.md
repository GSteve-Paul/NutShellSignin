# NutShellSignin · 果壳签到

NutShellSignin 是面向国科大课程签到的客户端，可登录、查看当天课表，并手动提交课程签到。

>[!CAUTION]
> **本项目仅供学习交流使用，请勿用于任何商业用途或非法用途。**

## 下载

请前往 [GitHub Releases](https://github.com/GSteve-Paul/NutShellSignin/releases)，下载适用于你设备的版本。页面未列出的平台暂时没有可用安装包；目前没有可直接安装的 iOS 版本。

## 使用

1. 输入学号和密码登录。
2. 可选择“记住账号密码”。下次打开应用时会自动填入，但不会自动登录或签到。
3. 登录后查看当天课表。签到时间为开课前 30 分钟至下课。
4. 选择课程后，核对课程和签到地点，再确认提交。
5. 如果提交后遇到超时，请先刷新课表确认签到状态，再决定是否重试。

## 签到地点

地点坐标不是通过设备 GPS 获取的。首次显示的坐标来自校区配置，请在提交前核对；你也可以修改坐标并保存常用地点。已保存地点会保留在本设备上，可从菜单中管理。

## 账号与隐私

只有开启“记住账号密码”时，凭据才会保存在本设备的系统安全存储中。你可以在菜单中退出登录，或选择同时删除已保存的账号密码。地点数据与账号密码分开保存。
